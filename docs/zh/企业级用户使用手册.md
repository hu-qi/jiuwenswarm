# 企业级用户使用手册

本文面向企业环境中的 JiuwenSwarm 使用者，介绍 Web 端常用功能、模型配置、定时任务、技能、记忆和权限提示等使用流程。

> 说明：本文为企业级用户手册基础版本，后续可结合实际企业版界面截图和部署方式继续补充。

---

## 1. 首次使用

首次进入 JiuwenSwarm Web 端后，建议按以下顺序完成配置和验证：

1. 打开 Web 页面。
2. 进入「配置信息」页面。
3. 配置模型服务。
4. 保存配置并验证模型连通性。
5. 回到对话页面，发送一条简单消息。
6. 根据任务复杂度选择规划、性能或集群模式。

---

## 2. 模型配置

企业环境中，模型服务可能来自公网模型服务、企业内模型服务或本地模型服务。配置前请确认：

| 配置项 | 说明 |
|--------|------|
| 模型服务地址 | 模型 API 的 base url 或网关地址 |
| 模型名称 | 当前要调用的模型名称 |
| 接口类型 | OpenAI 兼容接口或项目支持的其它接口类型 |
| 鉴权方式 | 按企业要求配置访问凭证 |
| 网络连通性 | JiuwenSwarm 服务所在环境需能访问模型服务 |

配置完成后，建议先进行一次基础对话，确认模型调用正常。

---

## 3. 对话与执行模式

JiuwenSwarm 支持多种任务执行方式：

| 模式 | 适用场景 |
|------|----------|
| 规划模式 | 任务较复杂，需要先拆解步骤再执行 |
| 性能模式 | 任务较简单，希望更快得到结果 |
| 集群模式 | 需要多个智能体协同完成复杂任务 |

使用建议：

- 简单问答、信息整理可使用性能模式。
- 报告、方案、代码修改等复杂任务优先使用规划模式。
- 多角色协作、跨模块分析等任务可使用集群模式。

---

## 4. 定时任务

定时任务用于让 JiuwenSwarm 按固定时间自动执行任务，例如每日提醒、定期总结、周期性查询等。

创建定时任务时，建议填写：

| 字段 | 说明 |
|------|------|
| 任务名称 | 便于识别任务用途 |
| Cron 表达式 | 定义任务触发时间 |
| 描述 | 用自然语言说明任务要做什么 |
| 时区 | 建议与企业实际使用地区保持一致 |
| 推送频道 | 选择 Web、TUI 或其它已启用频道 |
| 状态 | 启用或暂停任务 |

创建后可在定时任务页面查看任务状态、下次执行时间和执行结果。

---

## 5. 技能使用

技能用于沉淀可复用能力，例如信息查询、代码分析、文档生成、外部工具调用等。

使用技能前建议确认：

1. 技能是否已安装或启用。
2. 技能说明是否符合当前任务。
3. 技能是否需要额外配置。
4. 技能是否需要调用外部工具或访问文件。
5. 当前用户或工作区是否具备相应权限。

---

## 6. 记忆管理

记忆用于保存相对稳定的偏好、背景信息、项目经验或任务上下文。

企业场景中建议关注记忆范围：

| 范围 | 说明 |
|------|------|
| 个人记忆 | 仅服务当前用户 |
| 团队记忆 | 服务某个团队或项目空间 |
| 工作区记忆 | 服务当前企业工作区 |

使用建议：

- 只保存稳定、可复用的信息。
- 避免保存临时、过期或敏感信息。
- 定期检查并清理不再适用的记忆。

---

## 7. 权限提示

JiuwenSwarm 在执行工具调用、文件操作或外部能力时，可能根据配置进行允许、询问或拒绝。

常见提示包括：

| 提示类型 | 含义 |
|----------|------|
| allow | 当前操作可直接执行 |
| ask | 当前操作需要用户确认 |
| deny | 当前操作被策略拒绝 |

如果遇到操作被拒绝，请先确认：

1. 当前功能是否在企业策略允许范围内。
2. 文件路径是否在允许访问的工作区内。
3. 命令或工具是否属于受限制能力。
4. 管理员是否配置了更严格的策略。

---

## 8. 常见问题

| 问题 | 处理建议 |
|------|----------|
| 无法对话 | 检查模型配置和服务状态 |
| 定时任务没有执行 | 检查 Cron 表达式、任务状态和时区 |
| 技能无法调用 | 检查技能是否启用以及所需配置 |
| 记忆没有生效 | 检查记忆范围和状态 |
| 文件或命令被拒绝 | 检查权限策略和工作区范围 |
